# 風来のシレン6 便利ツール

ブラウザで開くだけで使える、風来のシレン6向けの非公式ツールです。無料・登録不要。

**▶ 使う: https://pteratakahashi.github.io/shiren6-tools/**

## 機能

- **ボヨヨン壁ルート検出** — スクショから配置を読み取り、増殖ルートを表示
- **値段識別** — 店の買値・売値から未識別アイテムを絞り込み
